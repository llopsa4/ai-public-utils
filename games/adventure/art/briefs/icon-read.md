## Description

Read people: a face in profile, looking right, with a small gold glint of insight above the brow (a thought caught). The same style, line weight and colours as the other action-ring icons (art/src/icons/look.png, talk.png...), so it sits in the ring beside them; it is also shown small (about 18 px) before a dialogue reply built on a reading, so it must read at that size.

## Use and placement

An action-ring icon.
