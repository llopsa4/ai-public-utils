# Changelog

## 0.2.0 — 2026-10-30

- Add the cinematic combat layout, original illustrated cards, and compact HP/MP displays.
- Preserve artwork proportions and stable card widths as cards leave the hand.
- Add reusable Kiln Pulse with energy, MP and strain costs.
- Configure battles from copied character profiles, encounter definitions and seeds while preserving the original encounter's deterministic behavior.
- Add the optional Tempered Flow signature upgrade, shared definition/affordability previews and explicit capped MP recovery helpers.
- Add development-only encounter/technique fixtures and expand automated coverage to 39 tests with 600 seeded balance simulations.

The normal game remains the standalone battle. Campaign scenes, branching maps, equipment and guided combat tutorials are not included yet. Development fixture controls are excluded from the generated game runtime.

## 0.1.0

Initial browser combat prototype and TypeScript/React/Vite foundation, published before versioned game release tags were introduced.
