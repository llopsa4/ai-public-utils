# Changelog

## 0.1.0 — pilot

- Phaser 3 + TypeScript engine at 640×360 with integer pixel scaling, served as static files from GitHub Pages.
- Two rooms (hotel hall, street) with polygon walk areas, obstacle holes, depth scaling and fade transitions.
- Hero and keeper characters with stand, walk (4 directions), crouch, lie-down-dead and a random 1.5–2.5 s idle blink.
- Action ring (radial verb menu) for mouse, keyboard and touch. Inventory with "use X on Y".
- Pilot puzzle: suitcase → key → locked door → street. Branching keeper dialogue gated by flags.
- English, Catalan and Spanish with a switcher.
- Save export/import as validated JSON files (no autosave).
- Placeholder art generator writing Aseprite-compatible sprite sheets.
